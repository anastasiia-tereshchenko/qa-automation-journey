# Python Fundamentals

This folder contains exercises completed via Codecademy to build a strong foundation for test automation. These scripts focus on core logic that is essential for writing robust test scripts.

## My Approach
Since I am in the early stages of learning Python, my focus in these exercises is:
* **Logic Building:** Understanding how to structure code, use loops, and handle conditional logic.
* **QA Observation:** Applying my testing mindset to how data inputs affect output — catching a range mismatch that would have produced empty output, and reordering conditional branches so a guard clause couldn't be bypassed.
* **Clean Code:** Practicing writing readable and organized code, which I know is a requirement for future automated test frameworks.

Each exercise here builds a foundation I'll use in automation — control flow for test logic, loops for iterating test data, functions for reusable test steps.

## Contents
*   **Magic 8 - Control Flow:** Project demonstrating conditional logic (`if`, `elif`, `else`) and input handling. 
*   **Carly's Clippers - Loops:** Implementation of loops and List Comprehensions.
*   **Physics Class - Functions:** Functions with parameters, return values, and default arguments for physics calculations.
