# Python Fundamentals

This folder contains exercises completed via Codecademy to build a strong foundation for test automation. These scripts focus on core logic that is essential for writing robust test scripts.

## QA-Driven Approach
In these exercises, I apply a tester's mindset to coding. For example, in Carly's Clippers, I analyzed data structures for potential boundary issues, and in Magic 8-Ball, I focused on logical flow and input handling. Beyond syntax, I evaluate these scripts for:
*   **Edge Cases:** Identifying boundary conditions and potential failure points within the logic.
*   **Test Design Techniques:** Applying concepts like Equivalence Partitioning and Boundary Value Analysis to the data inputs in my scripts to ensure robust coverage.
*   **Readability & Maintainability:** Writing clean code that is easy to debug and maintain, mirroring the standards required for scalable automated test frameworks.
*   **Data Validation:** Thinking about how to verify the outputs—a key skill for moving from Manual to Automation.

## Contents
*   **Magic 8 to cover Control Flow:** Project demonstrating conditional logic (`if`, `elif`, `else`) used to handle test scenarios and environment configurations.
*   **Carly's Clippers to cover Loops:** Implementation of loops and List Comprehensions, essential for data-driven testing and iterating through test elements.

## Key Skills Demonstrated
*   Writing clean, readable, and reusable Python code.
*   Applying logical operators to handle test assertions.
*   Managing test data structures.
