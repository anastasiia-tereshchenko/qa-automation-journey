# Python Fundamentals

This folder contains exercises completed via Codecademy to build a strong foundation for test automation. These scripts focus on core logic that is essential for writing robust test scripts.

## Contents
*   **Magic 8 to cover Control Flow:** Project demonstrating conditional logic (`if`, `elif`, `else`) used to handle test scenarios and environment configurations.
*   **Carly's Clippers to cover Loops:** Implementation of loops and List Comprehensions, essential for data-driven testing and iterating through test elements.

## Key Skills Demonstrated
*   Writing clean, readable, and reusable Python code.
*   Applying logical operators to handle test assertions.
*   Managing test data structures.

*Focus: Mastering the syntax required to build automated test frameworks.*
